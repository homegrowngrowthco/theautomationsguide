# SEO Audit — theautomationsguide.com — 2026-06-14

**Verdict:** Technically one of the cleanest small-site SEO foundations you could ask for. Crawl, redirects, canonicalization, sitemap hygiene, structured data, and on-page tags are all correct, and Lighthouse scores SEO a perfect **1.00** on every page tested. There is exactly **one material problem: mobile performance / Core Web Vitals** (LCP ~7.5–7.8s, mobile Performance 0.65). Everything else is medium/low polish. Indexing is healthy — **67 of 89 URLs indexed**, the rest just brand-new and awaiting first crawl (details below).

Method: live `curl` (headers/redirects/robots/sitemap), local `npm run build` + new `qa/seo-scan.mjs` over the 141-page `dist/` (89 indexable, 52 noindex), and Lighthouse 13.x against **production** (not a preview).

## Critical

### C-1 — Mobile Core Web Vitals are failing
| Run | Perf | LCP | FCP | TBT | CLS |
|---|---|---|---|---|---|
| Home — desktop | **0.99** | 0.7s | 0.7s | 0ms | 0.002 |
| Home — mobile | **0.65** | **7.8s** | 4.1s | 110ms | 0 |
| Post — mobile | **0.67** | **7.5s** | 3.9s | 30ms | 0 |

Desktop is excellent; **mobile is well below the 0.80 floor and LCP is ~3x the 2.5s "good" threshold.** Google indexes mobile-first and LCP is a ranking signal, so this is the highest-value fix on the site. CLS and TBT are fine, so the problem is load/render speed (render-blocking CSS/fonts + un-deferred third-party JS: PostHog, GTM, the beehiiv form iframe + likely unoptimized hero/OG imagery).

**This is the exact class HGC just solved.** On homegrowngrowth.co, deferring analytics to first-interaction (`requestIdleCallback` fallback) plus image re-encode + cache headers took mobile Performance from 0.71 → 0.94 and LCP ~6.5s → ~2.4s (HGC Sessions 18–21). Porting that playbook here is the recommended path.

## Medium

### M-1 — Homepage + all 53 non-post pages have no `og:image` / `twitter:image`
Blog posts get a per-post generated OG image (`/og/<slug>.png`), but the homepage, `/blog`, `/about`, `/teams/*`, `/tools/*`, `/playbooks`, and every hub render **no social image at all** (confirmed: homepage has neither `og:image` nor `twitter:image`). Link shares on LinkedIn/X/Slack and AI/GEO answer surfaces show a bare text card. Fix: add one site-default `og:image` fallback in `BaseLayout` whenever a page doesn't set its own. (53 indexable pages.)

### M-2 — 82 of 89 indexable titles exceed the SERP width (>62 chars)
Blog-post titles run 69–98 chars *including* the ` — The Automations Guide` suffix (24 chars), so Google truncates the differentiating end of the title. Examples: `…with-kit-n8n-notion-in` post = 98 chars; `…apollo-vs-clay-vs-linkedin…` = 84. Tighten post titles toward ~55 chars before the suffix, or drop the brand suffix on already-long titles.

### M-3 — Accessibility 0.91 (mobile) — four failing audits
`color-contrast`, `frame-title` (the beehiiv subscribe **iframe has no `title` attribute** — one-line fix), `heading-order` (a heading level is skipped), and `label-content-name-mismatch` (a control's visible text ≠ its accessible name). Not a direct ranking factor, but it feeds UX + E-E-A-T/GEO trust signals, and `frame-title` + `heading-order` are quick wins.

## Low

- **L-1 — `<title>` separator is an em dash on 88/89 pages.** ` — The Automations Guide` both wastes a little SERP width and violates the no-em-dash house style. Swap to ` | ` (pipe — conventional and shorter). One change in the layout, sitewide.
- **L-2 — Two meta-description outliers:** `/blog/revops-automation-stack-2026/` is 183 chars (>165, will truncate); `/terms/` is 65 (thin). Trim / expand.
- **L-3 — Blog posts set `og:type: "website"`** instead of `"article"`. Minor social/semantic nicety; the `BlogPosting` JSON-LD already carries the real article semantics.
- **Best Practices capped at 0.77** (third-party cookies + CSP `unsafe-inline`). Not a ranking factor; tracked, not worth chasing.

## Confirmed correct — NOT findings
- Single-hop redirects: no-slash → slash (1 hop → 200), `www` → apex, `http` → `https`. No chains.
- `robots.txt` allows all + explicitly allows AI crawlers (GPTBot/ClaudeBot/PerplexityBot/etc.); `Sitemap:` points at the live `sitemap-index.xml`.
- Sitemap (89 URLs) correctly excludes `/go/`, `/og/`, and the noindex utility pages — 0 leaks.
- **0 missing canonical, 0 duplicate titles, 0 multiple-H1, 0 missing meta description** across all 89 indexable pages.
- Rich, correct JSON-LD on posts: `BlogPosting`, `BreadcrumbList`, `FAQPage` + `Question`/`Answer`, `SoftwareApplication` (×6), `Person`, `Organization`, `ImageObject`.
- E-E-A-T signals live (Session 32): "By Ian Chamberland" byline → `/about/` `rel="author"`, TL;DR answer box, author JSON-LD.
- `/go/<tool>/` affiliate pages are `noindex,follow` + meta-refresh + sitemap-excluded — correct thin-redirect handling.
- Security headers all present (HSTS preload, X-Content-Type-Options, CSP, X-Frame-Options DENY).
