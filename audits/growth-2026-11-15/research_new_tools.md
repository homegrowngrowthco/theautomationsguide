# New-tool first-mover candidates and long-tail families (research date 2026-11-15)

Method and limits (read first)
- About 60 web searches plus page fetches. Reddit is not reachable by the search tool (domain blocked for this agent), so there are NO Reddit threads in this file. "Evidence people ask" is limited to Product Hunt launch pages, funding news, roundup posts and review-site presence. Treat demand as inferred, not measured. Check brand-name trend in Search Console / Trends before committing.
- Program status legend: VERIFIED = I read the vendor's own program page (or the PartnerStack/Reditus listing it links to) in this session. AGGREGATOR = only a directory/roundup said so. NONE FOUND = looked, nothing. UNKNOWN = not checked.
- Crowding legend: LOW = only vendor-run or competitor-run reviews plus a few directory stubs. MED = a handful of independent reviews and a small G2/Trustpilot base. HIGH = deep reviews on big sites.
- One page 403'd (salesflow.io/affiliates); recorded as blocked, not worked around. Several guessed program URLs 404'd (inboxkit /affiliate, zapmail, bitscale.ai/affiliate, aimfox, orangeslice.ai/affiliate, gojiberry.ai/affiliate, salesblink); those are UNKNOWN, not "no program".
- Excluded slugs were honoured. Prospeo and SyncGTM publish many "X review" pages; they are competitors for these queries (SyncGTM is also a candidate below).
